- Improved the image generation API: images are now always generated with a white background by default, so that the output resembles the document as displayed in a PDF viewer. Previously, PNG and WEBP images were generated with a transparent background. To restore the previous behavior, enable the new `ImageGenerationSettings.UseTransparentBackground` setting (applies only to image formats that support transparency: PNG and WEBP).
- Improved the developer experience when using `GeneratePdfAndShow` and `GenerateXpsAndShow` methods.
- Improved the stability of the QuestPDF Companion integration in various scenarios.
- The QuestPDF Companion app integration now requires dotnet 8 or higher.
- Improved semantic coverage by emitting the /BBox attribute for image elements (which is required by some PDF/UA-1 validators).
- Improved API consistency by deprecating the `AsSemanticHorizontalHeader` method in favor of `SemanticHorizontalHeader`.
- Fixed the Rotate API behavior by changing the rotation origin from the top-left corner to the center of the element. This is a breaking change, but center-origin rotation is the expected behavior in practically all use cases.
- Improved API naming consistency by deprecating the RotateLeft/RotateRight methods in favor of RotateLayoutCounterclockwise/RotateLayoutClockwise.
- Improved the automated table semantic tagging: it is now applied whenever the Table element is placed within the SemanticTable container, even indirectly. It also enables support for nested Semantic captions.
