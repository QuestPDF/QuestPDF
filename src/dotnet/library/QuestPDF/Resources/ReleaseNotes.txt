- Added the Compose method that places content produced by a separate method, for example page.Header().Compose(ComposeHeader).
- Added the Style and StyleIf methods that apply a reusable style and continue the Fluent API chain, for example table.Cell().Style(CellStyle).Text("Price"). StyleIf applies the style only when a condition is met.
- Marked the Element methods that accept a handler as obsolete. Use Compose when the call ends the statement, and Style when the Fluent API chain continues. Existing code keeps working.
